`ArcGISMapViewState.getMapViewHolder()` returns `AnyMapViewHolder?`. With `ArcGISMapView` (3D), `holder.map` can be cast to `ArcGIS.Scene`; with `ArcGISMapView2D` (2D), `holder.map` can be cast to `ArcGIS.Map`.
