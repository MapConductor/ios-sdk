`PolylineState` は `Polyline(state:)` で使用される `ObservableObject` です。

オーバーレイの宣言を再作成せずに、ルート、トラック、またはラインスタイルを更新する必要がある場合に使用してください。

## パブリックプロパティ

- `id: String`
- `strokeColor: UIColor`
- `strokeWidth: Double`
- `geodesic: Bool`
- `points: [GeoPointProtocol]`
- `extra: Any?`
- `onClick: OnPolylineEventHandler?`
