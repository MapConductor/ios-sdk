`GroundImageState` は `GroundImage(state:)` で使用される `ObservableObject` です。

実行時に画像、不透明度、地理的バウンズ、またはクリックハンドラーが変化する場合に使用してください。

## パブリックプロパティ

- `id: String`
- `bounds: GeoRectBounds`
- `image: UIImage`
- `opacity: Double`
- `tileSize: Int`
- `extra: Any?`
- `onClick: OnGroundImageEventHandler?`
