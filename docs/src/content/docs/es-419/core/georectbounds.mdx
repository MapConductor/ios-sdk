`GeoRectBounds` almacena las esquinas opcionales suroeste y noreste, y puede extenderse con puntos.

<GeoRectBoundsBasicExample swLat={35.67} swLon={139.74} neLat={35.69} neLon={139.76} />

## API pública

- `isEmpty: Bool`
- `southWest: GeoPoint?`
- `northEast: GeoPoint?`
- `center: GeoPoint?`
- `extend(point:)`
- `contains(point:)`
- `union(other:)`
- `toSpan() -> GeoPoint?`
- `toUrlValue(precision:)`
- `expandedByDegrees(latPad:lonPad:)`
- `intersects(other:)`

Usa `southWest`, `northEast`, `toSpan()` e `isEmpty` para inspeccionar los límites.

## Construir límites desde puntos

<GeoRectBoundsFromPointsExample zoom={12} durationMillis={300} />

Para mover la cámara de modo que los límites sean visibles, usa `fitBounds(bounds:padding:)`:

<GeoRectBoundsFitBoundsExample padding={32} />

Para mayor control sobre el nivel de zoom resultante, calcula la posición de cámara deseada y llama a `moveCameraTo(cameraPosition:durationMillis:)`.

## Contenido e intersección

Los límites son útiles para filtrar datos visibles, detectar superposición entre regiones y construir superposiciones de depuración.

<GeoRectBoundsContainmentExample />

## Mostrar límites

Para mostrar el contorno de un límite rectangular, pasa los límites a `Polyline`:

<GeoRectBoundsPolylineExample strokeWidth={2} />

Usa `expandedByDegrees(latPad:lonPad:)` cuando necesites un margen simple en grados alrededor de unos límites existentes. Esto no reemplaza el ajuste de cámara; solo devuelve un rectángulo geográfico más grande.
